
# Personal Expense Tracker

A Python application for recording expenses and
calculating monthly financial balances.

## Features

- Accepts monthly income from the user
- Records multiple expenses
- Calculates total expenses and remaining balance
- Validates monetary input
- Displays a financial summary

## Project Structure

- `01_variables_and_data_types.py` — Variables and data types
- `02_operators_and_calculations.py` — Arithmetic and comparisons
- `03_lists_and_arrays.py` — Lists and collection operations
- `04_loops.py` — Repetition and iteration
- `05_functions.py` — Reusable functions
- `06_user_input_and_validation.py` — Input and error handling
- `expense_tracker.py` — Main expense tracker application

## Requirements

- Python 3

## How to Run

Open a terminal in the project directory and run:

    python expense_tracker.py

You can also run each numbered file separately to
explore its programming concepts.
